# MACD + VFI Trading Strategy

A simple and clean backtesting tool for the **MACD(8,21,5) + VFI(65)** strategy with ATR-based Stop Loss and Take-Profit.

### Features
- Interactive mode (test any ticker one by one)
- ATR Stop + Take Profit
- Optional Trailing Stop
- Equity curve chart
- Clear performance metrics (Return, Profit Factor, Max Drawdown, Win Rate, etc.)
